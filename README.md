# funpromotion
运行在 `chatgpt.com` 上的浏览器 userscript，用于在 ChatGPT workspace 中提交加入/接受邀请请求并导出相关凭证配置。

`k12-v1.js` 适用于手动填写 workspace ID 并发起请求；`k12-v2.js` 提供更新版本的批量处理界面，使用前请确认目标 workspace 和账号权限。

## 使用

1. 在已登录 ChatGPT 的浏览器中安装 Tampermonkey 等 userscript 管理器。
2. 新建脚本，复制 `codex/v20260705-linuxdo/k12-v1.js` 的内容并保存。
3. 打开 [chatgpt.com](https://chatgpt.com/)，在面板中填写母号 workspace ID，点击 Request。

也可以直接使用仓库中的脚本文件导入 userscript 管理器。
